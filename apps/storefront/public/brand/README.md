# Brand logo slot

Place the customer's logo here exactly as supplied, with no recolouring or redrawing:

- `logo.svg` (preferred) or `logo.png` / `logo.webp`, transparent background.

The header and footer render whichever of these files exists (`src/components/brand-logo.tsx`), scaled to
fit a 40–48px tall box with the original proportions. If no file is present the brand name is shown as
text. Do not commit any other files here.
